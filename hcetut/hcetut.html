I.II: install Chimera

the latest version of Chimera is available Here.
just extract the files in the archive to your HCE install folder and BLAM ! ur done. you can toggle some options in the "chimera.ini" file if you want.

I.III: Install CEnshine

Get the Latest verion of CEnshine Here and put the file in the "Shaders" folder of ur HCE install.

Step II: Install Halo: Refined (Campaign and graphical fixes)

download the Halo CE Refined mod here (halo_refined_custom_edition_en_v5.01.7z) and extract the ".map" files in your "maps" folder.
this gives you higher resolution HUD and Textures for both MP and SP maps.

and thats it. you are done with installing the most Xbox Accurate version of Halo CE on PC.

Optional Stuff:

Custom Maps:

as mentioned before, you can get custom maps for Halo CE from HaloMaps.org this includes SinglePlayer, FireFight, and Multiplayer maps/
you can install by putting it in ur maps folder and using the Halo Universal UI 1.1 mod to load them. just back up your original main menu before installing this.

Installing Mercury:

Mercury is a mod manager and installer for Halo Custom Edition. it hosts some mods including chimera wich you can use Mercury to install it.
you can get the Insurrection mod for Halo CE using it wich is another main menu mod. get it Here
